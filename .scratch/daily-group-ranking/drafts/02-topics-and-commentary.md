# 02: 在排行榜中附加热门话题与趣味点评

**What to build:** 在“谁最能聊”的同一条结果中，展示最多 3 个当天热门话题和一句模板点评。模型不可用时仍正常显示排行榜，成员姓名、发言次数及排序始终由统计代码确定。

**Blocked by:** 01 — 群内“谁最能聊”当日文本排行榜。

**Status:** draft

## Acceptance criteria

- [ ] 仅使用本次统计合格的文本，按时间排序后最多均匀抽取 100 条，每条最多 200 个字符；不传入额外的姓名、senderId、群 ID、消息 ID 或排行榜数据。
- [ ] 有效文本少于 5 条时不调用模型，话题部分显示“今天还没有聊出明显的话题”，省略点评；空排行沿用任务 01 的空结果提示。
- [ ] 使用当前会话配置的 AstrBot Provider 独立调用一次，超时上限 8 秒，不重试、不附带日常会话历史、不开放工具。聊天记录仅作为分析数据，不能执行其中的指令。
- [ ] 解析话题字符串数组，最多保留 3 个非空、去重后的话题，每项最多 20 个字符；模型返回空数组时显示无明显话题提示并省略点评。
- [ ] Provider 不可用、超时、异常或结果无法解析时，省略话题与点评，仍返回任务 01 的正确排行榜；不因模型结果改动统计数字，不额外发送失败提示。
- [ ] 仅在存在话题时使用简短预定义模板生成点评，不额外调用模型；使用排行榜第一名和已有话题，不推断性格或私人情况。点评标题取机器人实际显示名称，不可用时使用“机器人点评”，不写死昵称。
- [ ] 排行、话题、点评合并成同一条纯文本后再发送，沿用任务 01 的去重、来源有效性和熔断检查；正常结果没有尾注，部分统计只保留简短提示。样本仅用于本次请求，日志不记录正文、样本或 Token。
- [ ] 仅补齐 SPEC 中第 5 类核心测试：模型正常时有话题，模型不可用时仍返回相同的正确排行；结合任务 01 现有用例确认单条回复，定向静态检查和测试通过。
