# WeChat Native 面板

已确认：将连接测试页升级为紧凑面板。顶部放机器人选择、Native / 微信状态和刷新按钮；桌面四列、手机两列显示今日接收、今日已回复、今日失败、待核对；下方是约 180px 高的最近七天双系列柱形图，以及折叠配置概览。

使用现有 HTML / CSS / JavaScript、SVG 和 SQLite，不增加依赖。统计按机器人独立持久化，按服务端本地接收日期汇总当前消息状态；分段回复按原消息计一次。只统计实时收到的入站消息，重放去重，部分发送与失败、待核对分开。待核对卡片显示全部未解决的待核对及部分发送消息。

取舍：纯内存计数无法跨重启保留；独立每日累加器需要同步所有状态转换。采用独立接收日表关联现有消息状态，查询时按日汇总，复用现有状态转换与恢复逻辑。

统计从升级启用时开始，之前日期显示未采集。面板只读打开既有数据库，不创建适配器或触发启动恢复。空配置、旧数据库、不可读数据库显示明确状态。配置只返回白名单中的开关及数量；保留现有连接检测接口与路径。自动刷新每 30 秒一次，后台页面暂停。
